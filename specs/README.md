# Bendi Go Milestones

Each PRD describes one milestone. Every milestone ends with a version of the game that is published to Roblox and that a kid can play and learn something from. Milestones are built in order, because each one builds on the previous one.

| PRD | Milestone | What players get |
| :-- | :-------- | :--------------- |
| [PRD-001](prd-001-drive-around-town.md) | Drive Around Town | A car to drive around a small Israeli neighborhood |
| [PRD-002](prd-002-traffic-lights-and-stars.md) | Traffic Lights and Stars | Traffic lights, stars for stopping at red, friendly tips from Bendi |
| [PRD-003](prd-003-speed-limits.md) | Speed Limits | Speed signs, a speedometer, and stars for keeping to the limit |
| [PRD-004](prd-004-pedestrian-crossings.md) | Pedestrian Crossings | People crossing the street, and stars for letting them cross |
| [PRD-005](prd-005-roundabouts-and-yielding.md) | Roundabouts and Yielding | Other cars on the road, roundabouts, stop and give-way signs |
| [PRD-006](prd-006-driving-lessons-and-license.md) | Driving Lessons and License | Guided lessons, saved progress, and a Bendi Go driving license |

## Rules for every milestone

These apply to all PRDs and are not repeated in each one.

- **Israeli rules, correctly.** Cars drive on the right. Speeds are in km/h. Signs, road markings, and traffic lights look and behave like they do in Israel. When unsure about a rule, check the official Israeli traffic regulations before building it.
- **Kind feedback.** The game never takes stars away and never punishes the player. A mistake shows a short, friendly tip that explains the rule. Stars only reward doing the right thing.
- **Easy to read.** All player-facing text is short, in English and Hebrew, and goes through one localization table so more languages can be added later.
- **Safe for kids.** No chat features beyond Roblox defaults, no purchases, and no way for one player to bother another (player cars do not collide with each other).
- **Done means published.** A milestone is done when it is published to the Bendi Go Roblox place and Ben has played it and confirmed every acceptance criterion.
